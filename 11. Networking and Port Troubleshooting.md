# 11. Networking and Port Troubleshooting

## 11.1 Basic network information

```bash
hostname                    # Show hostname
ip addr                     # Show interfaces and IP addresses
ip route                    # Show routing table
ip link                     # Show network interfaces and link state
```

`ifconfig` is an older utility and may not be installed by default. Prefer the modern `ip` command.

## 11.2 Private IP vs public IP

- A **private IP address** is used for communication within private networks and is not directly globally routable.
- A **public IP address** is globally routable on the internet, subject to network configuration and security controls.

```bash
ip addr
curl https://ifconfig.me
```

The second command asks an external service to report the public source IP it sees. Behind NAT, this may be the NAT gateway's public IP rather than an address configured directly on the Linux machine.

## 11.3 Ports and listening services

An IP address identifies a network interface/host in an IP network. A **port** identifies an application endpoint on a host.

For example, SSH commonly listens on TCP port 22.

Preferred modern command:

```bash
sudo ss -tulpn
```

Legacy alternative (may require installing `net-tools`):

```bash
sudo netstat -tulpn
```

Options:

| Option | Meaning |
|---|---|
| `-t` | TCP sockets |
| `-u` | UDP sockets |
| `-l` | Listening sockets |
| `-p` | Show process information where permitted |
| `-n` | Numeric addresses and ports; do not resolve names |

Other useful commands:

```bash
sudo ss -lntp              # Listening TCP sockets
sudo ss -lunp              # Listening UDP sockets
sudo lsof -i :22           # Processes using port 22 (if lsof is installed)
```

## 11.4 Test whether a remote port is reachable

```bash
nc -vz 192.168.1.20 22
```

Or, if available:

```bash
telnet 192.168.1.20 22
```

This tests a TCP connection to port 22 on the **remote host**. It does not prove that SSH authentication will succeed; it only tests connectivity to the port.

To test a service on your own machine, use its local address:

```bash
nc -vz 127.0.0.1 22
```

**Important:** Telnet is unencrypted and should not be used to administer servers. It is shown here only as a basic TCP connectivity test. Prefer `nc` for this purpose.

## 11.5 Apache web server

Apache HTTP Server is web-server software that listens for HTTP/HTTPS requests and serves web content.

- Ubuntu/Debian package and service name: commonly `apache2`
- RHEL-family package and service name: commonly `httpd`

They are distribution-specific packaging/service conventions for the same Apache HTTP Server project.

Ubuntu examples:

```bash
sudo apt install apache2
sudo systemctl status apache2
sudo systemctl enable --now apache2
```
