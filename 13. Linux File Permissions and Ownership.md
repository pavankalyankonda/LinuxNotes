# 13. Linux File Permissions and Ownership

Linux permissions determine who can read, modify or execute a file and who can access a directory.

## 13.1 The three permission classes

- `u` = user/owner
- `g` = group
- `o` = others

The three basic permissions:

| Permission | File meaning | Directory meaning |
|---|---|---|
| `r` | Read file contents | List directory entries |
| `w` | Modify file contents | Create, delete or rename entries (subject to other controls) |
| `x` | Execute file | Traverse/access entries by name |

Example:

```bash
ls -l file1
```

Possible output:

```text
-rw-r--r-- 1 konda konda 120 Nov 16 10:00 file1
```

Breakdown:

```text
- rw- r-- r--
|  |   |   |
|  |   |   +--- Others: read
|  |   +------- Group: read
|  +----------- Owner: read and write
+-------------- Regular file
```

A leading `d` means directory; `l` means symbolic link.

## 13.2 Numeric permissions

| Number | Permission |
|---:|---|
| 4 | Read (`r`) |
| 2 | Write (`w`) |
| 1 | Execute (`x`) |

Add the values:

- `7` = 4 + 2 + 1 = `rwx`
- `6` = 4 + 2 = `rw-`
- `5` = 4 + 1 = `r-x`
- `4` = read only

Examples:

```bash
chmod 644 file1
chmod 600 file1
chmod 755 script.sh
chmod 700 private-directory
```

| Mode | Owner | Group | Others | Common use |
|---|---|---|---|---|
| `644` | `rw-` | `r--` | `r--` | Ordinary file |
| `600` | `rw-` | `---` | `---` | Private file |
| `755` | `rwx` | `r-x` | `r-x` | Executable or accessible directory |
| `700` | `rwx` | `---` | `---` | Private directory |

A user being a member of a file's group does not automatically grant access. The file's group permissions must allow the required operation, and directory permissions along the path must also permit access.

## 13.3 Change ownership

```bash
sudo chown john file1
sudo chown john:john file1
sudo chown -R john:john /opt/myapp
```

- `chown` = change owner
- `john:john` = user `john`, group `john`
- `-R` = recursive; applies to the directory tree

Use recursive ownership changes carefully.

## 13.4 umask

**umask** is the permission mask applied when new files and directories are created. It removes permissions from the creation defaults.

Common defaults before umask:

- Regular files: `666` (files are not created executable by default)
- Directories: `777`

With a common umask of `022`:

```text
Files:       666 -> 644
Directories: 777 -> 755
```

Check the current mask:

```bash
umask
umask -S
```

Set it for the current shell:

```bash
umask 022
```

**Note:** The exact resulting permissions can also be affected by the application creating the file. umask is a mask, not a command that assigns one fixed permission to every new file.
