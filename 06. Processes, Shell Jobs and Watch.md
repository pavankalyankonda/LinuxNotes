# 6. Processes and Shell Jobs

## 6.1 What is a process?

A **process** is a running instance of a program. The Linux kernel assigns it a Process ID (**PID**).

A process may have a parent process, identified by its Parent Process ID (**PPID**).

## 6.2 What is a shell job?

A **job** is a shell-level representation of one or more processes started or managed by a particular interactive shell.

- A process is managed by the operating system and has a PID.
- A job is managed by the shell and has a job number such as `%1`.
- One job can contain more than one process, for example a pipeline.

**Important:** `jobs` shows jobs belonging to the current shell. It is not a system-wide process listing.

## 6.3 Foreground and background jobs

A foreground job occupies the terminal until it finishes or is suspended.

A background job runs without keeping the terminal occupied.

```bash
sleep 100              # Run in the foreground
sleep 100 &            # Run in the background
jobs                   # List jobs in this shell
jobs -l                # List jobs and their PIDs
```

Example:

```bash
sleep 500 &
sleep 200 &
jobs
```

Possible output:

```text
[1]-  Running    sleep 500 &
[2]+  Running    sleep 200 &
```

- `[1]` and `[2]` are shell job numbers.
- `+` identifies the current job for job-control commands.
- `-` identifies the previous job.
- These symbols do not indicate priority or remaining runtime.

## 6.4 Job-control commands

| Command / key | Purpose |
|---|---|
| `jobs` | List jobs in the current shell |
| `jobs -l` | Include process IDs |
| `command &` | Start a command in the background |
| `fg %1` | Bring job 1 to the foreground |
| `bg %1` | Resume a suspended job in the background |
| `Ctrl + Z` | Suspend the current foreground job |
| `kill %1` | Send a termination signal to job 1 |
| `wait %1` | Wait for job 1 to finish |

Example:

```bash
sleep 300
# Press Ctrl+Z to suspend it

jobs
bg %1
jobs
fg %1
```

To stop the foreground command, press `Ctrl+C`.

## 6.5 The `watch` command

`watch` repeatedly executes a command and refreshes its output.

```bash
watch date
watch -n 2 date
watch -n 5 free -h
```

- `-n 2` = refresh every 2 seconds.
- `watch jobs` usually cannot show the interactive shell's job table because `watch` runs the command in a separate execution context.

To monitor processes, use:

```bash
ps -ef | grep '[s]leep'
watch -n 2 "ps -ef | grep '[s]leep'"
```
