# 23. Secure File Transfer with SCP

## 23.1 What is SCP?

**SCP (Secure Copy)** transfers files between systems using SSH.

It encrypts the transfer and uses SSH authentication, such as a password or private key.

General syntax:

```bash
scp [OPTIONS] SOURCE DESTINATION
```

## 23.2 Copy a file from the local machine to a remote server

Run on the source machine:

```bash
scp /home/konda/hello.sh azureadmin@192.168.1.20:/home/azureadmin/
```

Syntax:

```text
scp SOURCE_FILE USERNAME@DESTINATION_IP:DESTINATION_PATH
```

## 23.3 Copy a directory

Use `-r` for recursive copying:

```bash
scp -r /home/konda/scripts azureadmin@192.168.1.20:/home/azureadmin/
```

## 23.4 Copy from a remote server to the local machine

```bash
scp azureadmin@192.168.1.20:/home/azureadmin/hello.sh /home/konda/
```

The remote location is the source and the local path is the destination.

## 23.5 Use a specific SSH private key

```bash
scp -i ~/.ssh/id_rsa hello.sh azureadmin@192.168.1.20:/home/azureadmin/
```

The private key must be protected and readable only by the appropriate user.

## 23.6 Use a non-default SSH port

```bash
scp -P 2222 hello.sh azureadmin@192.168.1.20:/home/azureadmin/
```

**Remember:** SCP uses uppercase `-P` for the port. Lowercase `-p` preserves file modification times and modes.
