# 21. Aliases and Shell Configuration

An **alias** is a shortcut name for a command or command sequence in a shell.

Example:

```bash
alias ku='kubectl'
ku get nodes
```

To make the alias available in future Bash sessions, add it to `~/.bashrc`:

```bash
echo "alias ku='kubectl'" >> ~/.bashrc
source ~/.bashrc
```

- `~/.bashrc` is commonly read when an interactive non-login Bash shell starts.
- `source ~/.bashrc` reads the file into the current shell, applying changes immediately.

List aliases:

```bash
alias
```

Remove an alias from the current shell:

```bash
unalias ku
```

Aliases are convenient for interactive use. For scripts, prefer explicit commands or functions so behaviour is predictable.
