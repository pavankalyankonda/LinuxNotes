# **TMUX**

**TMUX** is a terminal multiplexer. It allows you to create multiple terminal sessions, windows, and panes, even after disconnecting from SSH.

## **1. Session Commands**

```
tmux                         # Start a new session
tmux new -s test             # Create a named session
tmux ls                      # List all sessions
tmux attach -t test          # Attach to session named test
tmux a                       # Attach to the most recent session
tmux detach                  # Detach from current session
tmux kill-session -t test    # Delete session named test
tmux kill-server             # Kill all tmux sessions
```

## **2. Keyboard Shortcuts**

All shortcuts start with `Ctrl + b`, followed by another key.

| Shortcut               | Description                |
| ---------------------- | -------------------------- |
| `Ctrl + b`, then `c`   | Create new window          |
| `Ctrl + b`, then `,`   | Rename current window      |
| `Ctrl + b`, then `n`   | Move to next window        |
| `Ctrl + b`, then `p`   | Move to previous window    |
| `Ctrl + b`, then `0-9` | Switch to window by number |
| `Ctrl + b`, then `w`   | List and select windows    |
| `Ctrl + b`, then `&`   | Close current window       |
| `Ctrl + b`, then `d`   | Detach from session        |
| `Ctrl + b`, then `?`   | Show all shortcuts         |

## **3. Pane Commands**

Panes divide one window into multiple terminals.

| Shortcut                     | Description                     |
| ---------------------------- | ------------------------------- |
| `Ctrl + b`, then `%`         | Split vertically (left/right)   |
| `Ctrl + b`, then `"`         | Split horizontally (top/bottom) |
| `Ctrl + b`, then `o`         | Switch to next pane             |
| `Ctrl + b`, then `x`         | Close current pane              |
| `Ctrl + b`, then `arrow key` | Move between panes              |
| `Ctrl + b`, then `z`         | Zoom/unzoom current pane        |
| `Ctrl + b`, then `q`         | Show pane numbers               |

## **4. Useful Commands**

```
tmux new -s devops           # Create DevOps session
tmux attach -t devops        # Reconnect to DevOps session
tmux rename-session -t old new  # Rename a session
tmux kill-session -t devops  # Delete DevOps session
```

## **5. Remember**

- **Session** = A collection of windows.
- **Window** = A terminal screen inside a session.
- **Pane** = A split section inside a window.
- **Detach** = Leave the session running in the background.
- **Attach** = Reconnect to an existing session.

**Example workflow:**

```
tmux new -s devops       # Create session
# Run your commands
Ctrl + b, then d         # Detach
tmux ls                  # Check sessions
tmux attach -t devops    # Reconnect
```

**Important:** When you detach, commands running inside the session continue running, even if you disconnect from SSH.
