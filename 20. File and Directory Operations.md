# 20. File and Directory Operations

## 20.1 List files

```bash
ls
ls -l                  # Long format
ls -a                  # Include hidden entries
ls -lh                 # Long format, human-readable sizes
ls -lt                 # Sort by modification time, newest first
ls -ltr                # Sort by modification time, oldest first
```

Hidden filenames normally begin with a dot, for example `.bashrc`.

## 20.2 Create directories

```bash
mkdir logs
mkdir -p app/config     # Create parent directories if needed
```

## 20.3 Copy files and directories

```bash
cp file1 file2
cp file1 /tmp/
cp -r dir1 dir2
```

- `cp file1 file2` copies file1 to a new or existing file2.
- `cp file1 /tmp/` copies file1 into `/tmp`.
- `cp -r` recursively copies a directory tree.

For preserving more metadata when copying, consider:

```bash
cp -a source/ destination/
```

## 20.4 Move and rename

```bash
mv file1 file2          # Rename file1 to file2
mv file1 /tmp/          # Move file1 into /tmp
mv dir1 dir2            # Rename/move a directory
```

## 20.5 Remove files and directories

```bash
rm file1
rmdir empty-directory
rm -r directory
```

`rm -r` recursively removes a directory and its contents.

**Danger:** `rm -rf` forces recursive deletion and suppresses many prompts/errors. A command such as `rm -rf *` removes matching entries in the current directory. Always check `pwd` and the exact target before running destructive commands.

Safer habit:

```bash
pwd
ls -la
rm -ri directory
```

`-i` asks before each removal.
