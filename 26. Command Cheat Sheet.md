# Command Cheat Sheet

## System and OS

| Command | Use |
|---|---|
| `man <command>` | shows command usage manual |
| `ncal` | shows calendar, 'cal' can also be used |
| `uname -a` | Kernel/system information |
| `uname -r` | Kernel version |
| `uname -m` | CPU architecture |
| `cat /etc/os-release` | Distribution/version |
| `hostnamectl` | Hostname and OS information |
| `lscpu` | CPU details |
| `free -h` | Memory usage |
| `df -h` | Filesystem capacity |
| `df -i` | Inode usage |
| `du -sh PATH` | Directory size |
| `uptime` | Uptime and load averages |

## Processes and services

| Command | Use |
|---|---|
| `ps -ef` | List processes |
| `ps -p PID -o pid,ppid,cmd` | Inspect a process |
| `pgrep -a NAME` | Find process by name |
| `top` | Interactive process monitor |
| `jobs` | Current shell jobs |
| `jobs -l` | Jobs with PIDs |
| `systemctl status NAME` | Service status |
| `systemctl restart NAME` | Restart service |
| `systemctl enable NAME` | Enable service at boot |
| `kill PID` | Request graceful process termination |
| `kill -9 PID` | Force process termination |

## Networking

| Command | Use |
|---|---|
| `ip addr` | IP addresses/interfaces |
| `ip route` | Routing table |
| `ss -tulpn` | Listening TCP/UDP sockets |
| `ss -lntp` | Listening TCP sockets |
| `curl URL` | Make an HTTP request |
| `curl https://ifconfig.me` | Ask an external service for observed public IP |
| `nc -vz HOST PORT` | Test TCP connectivity |
| `hostname` | Hostname |

## Users and permissions

| Command | Use |
|---|---|
| `id USER` | UID, GID and groups |
| `groups USER` | Group memberships |
| `useradd -m USER` | Create user with home directory |
| `adduser USER` | Interactive user creation on Ubuntu |
| `passwd USER` | Set/change password |
| `usermod -aG GROUP USER` | Add supplementary group |
| `chmod 644 FILE` | Change permissions |
| `chown USER:GROUP FILE` | Change ownership |
| `umask` | Display permission mask |

## Files and text

| Command | Use |
|---|---|
| `pwd` | Current directory |
| `ls -lah` | Detailed listing including hidden files |
| `touch FILE` | Create file/update timestamps |
| `cp SRC DEST` | Copy |
| `mv SRC DEST` | Move/rename |
| `rm FILE` | Remove file |
| `mkdir -p DIR` | Create directory tree |
| `find PATH -name NAME` | Find by name |
| `file FILE` | Identify file type |
| `grep -in PATTERN FILE` | Case-insensitive search with line numbers |
| `cut -d: -f1 FILE` | Extract delimited field |
| `sed 's/old/new/g' FILE` | Transform text in output |
| `head -n 20 FILE` | First 20 lines |
| `tail -n 20 FILE` | Last 20 lines |
| `tail -f FILE` | Follow a log |
| `less FILE` | Browse a file |

## Archives and transfer

| Command | Use |
|---|---|
| `tar -cvf a.tar DIR/` | Create tar archive |
| `tar -xvf a.tar` | Extract tar archive |
| `tar -czvf a.tar.gz DIR/` | Create gzip-compressed tar |
| `tar -xzvf a.tar.gz` | Extract gzip-compressed tar |
| `tar -tzvf a.tar.gz` | List compressed tar contents |
| `gzip FILE` | Compress file |
| `gunzip FILE.gz` | Decompress file |
| `scp FILE USER@HOST:/PATH/` | Securely copy file to remote host |
| `scp -r DIR USER@HOST:/PATH/` | Securely copy directory |

## Scheduling and logs

| Command | Use |
|---|---|
| `crontab -l` | List current user's cron jobs |
| `crontab -e` | Edit current user's cron jobs |
| `systemctl status cron` | Check cron service |
| `journalctl -u SERVICE` | Read service logs |
| `journalctl -b` | Current boot logs |
| `journalctl -f` | Follow journal entries |
| `journalctl --since today` | Logs since today |
