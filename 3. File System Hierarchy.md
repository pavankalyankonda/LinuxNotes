# 3. Linux Filesystem Hierarchy

Linux organizes files under one directory tree. The top of this tree is called the **root directory**, represented by `/`.

A directory such as `/home/konda` is a path inside that single tree. Linux does not use drive letters in the same way Windows does.

## 3.1 Important directories

| Directory | Purpose | Example |
|---|---|---|
| `/` | Root of the entire filesystem tree | Every Linux path starts here |
| `/home` | Home directories for normal users | `/home/konda` |
| `/root` | Home directory of the root user | `/root/.ssh` |
| `/etc` | System-wide configuration files | `/etc/ssh/sshd_config` |
| `/var` | Frequently changing data such as logs and caches | `/var/log` |
| `/var/log` | System and application logs | `/var/log/syslog` |
| `/usr` | Most user-space applications, libraries and shared data | `/usr/bin`, `/usr/lib` |
| `/usr/bin` | Many user commands | `ls`, `grep` |
| `/usr/sbin` | Many system-administration executables | `sshd` may be here on Ubuntu |
| `/usr/local` | Software installed locally by an administrator | `/usr/local/bin` |
| `/opt` | Optional or third-party application software | `/opt/vendor-app` |
| `/bin` | Essential user commands; commonly linked into `/usr/bin` on modern Ubuntu | `sh`, `ls` |
| `/sbin` | Essential system commands; commonly linked into `/usr/sbin` | Administration utilities |
| `/lib` | Essential shared libraries and kernel modules; commonly linked into `/usr/lib` | `/lib/modules` |
| `/dev` | Device files representing devices and virtual devices | `/dev/sda`, `/dev/null` |
| `/proc` | Virtual filesystem exposing process and kernel information | `/proc/cpuinfo` |
| `/sys` | Virtual filesystem exposing devices and kernel interfaces | `/sys/class/net` |
| `/run` | Runtime state created since boot | PID files, sockets |
| `/tmp` | Temporary files | Temporary application data |
| `/mnt` | Common temporary mount point for filesystems | `/mnt/data` |
| `/media` | Common mount point for removable media | USB storage |

### A useful way to remember

- `/etc` = configuration
- `/var/log` = logs
- `/home` = normal users' personal files
- `/root` = root user's home
- `/usr` = installed user-space software and shared data
- `/opt` = optional/third-party applications
- `/tmp` = temporary files
- `/proc` and `/sys` = kernel-provided system information

## 3.2 Explore the filesystem

```bash
pwd                    # Print the current working directory
ls                     # List directory contents
ls -la                 # Include hidden files and detailed information
cd /etc                # Change directory
cd ~                   # Go to your home directory
cd ..                  # Go to the parent directory
tree /etc              # Display a directory tree (install tree if needed)
```

**Absolute path:** Starts at `/`, for example `/home/konda/notes.txt`.

**Relative path:** Starts from the current directory, for example `notes.txt` or `../logs/app.log`.
