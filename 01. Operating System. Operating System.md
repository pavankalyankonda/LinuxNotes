# 1. Linux and Operating Systems

## 1.1 What is an operating system?

An **operating system (OS)** is system software that manages computer hardware and provides services to applications.

It acts as the layer between applications and physical hardware.

For example, when a browser needs memory, network access or disk storage, it requests those resources through the operating system rather than controlling the hardware directly.

### Main responsibilities of an OS

| Responsibility | What it does |
|---|---|
| Process management | Creates, schedules and terminates processes |
| Memory management | Allocates and manages RAM |
| File management | Organizes files, directories and storage |
| Device management | Communicates with disks, network cards and other devices |
| Networking | Provides network communication capabilities |
| Security | Manages users, permissions and access controls |

## 1.2 What is Linux?

**Linux is an open-source, Unix-like operating-system kernel.** A complete Linux operating system normally combines the Linux kernel with system tools, libraries, package management and applications.

Examples of Linux distributions (distros):

- Ubuntu
- Debian
- Red Hat Enterprise Linux (RHEL)
- Rocky Linux
- AlmaLinux
- Fedora
- SUSE Linux Enterprise

A **distribution** packages the Linux kernel with software, configuration defaults and tools to provide a usable operating system.

## 1.3 Linux vs Windows

| Area | Linux | Windows |
|---|---|---|
| Source model | Mostly open-source components | Primarily proprietary |
| Common administration | Shell/terminal and graphical tools | PowerShell, Command Prompt and graphical tools |
| Filesystem layout | One directory tree starting at `/` | Drive letters such as `C:\` and `D:\` |
| Case sensitivity | Usually case-sensitive | Usually case-insensitive by default |
| Software installation | Package managers such as `apt` or `dnf` | Installers, Microsoft Store, package managers |
| Common server use | Cloud, containers, web servers, automation | Windows Server, Active Directory, enterprise applications |

**Important:** Linux is not just a command-line operating system. It can have a graphical desktop too. Servers often use a command line because it is efficient to administer remotely and automate.
