# 14. Archiving and Compression

## 14.1 Archive vs compression

These concepts are related but different:

- **Archiving** combines multiple files/directories into one archive.
- **Compression** reduces the size of data using a compression algorithm.

`tar` creates and extracts archives. gzip compresses and decompresses data. A `.tar.gz` file is a tar archive compressed with gzip.

## 14.2 gzip and gunzip

```bash
gzip file.txt              # Compress; commonly creates file.txt.gz
gunzip file.txt.gz         # Decompress
gzip -k file.txt           # Keep the original file as well
```

## 14.3 tar commands

### Create an uncompressed tar archive

```bash
tar -cvf files.tar files/
```

### Extract an uncompressed archive

```bash
tar -xvf files.tar
```

### Create a gzip-compressed tar archive

```bash
tar -czvf files.tar.gz files/
```

### Extract a gzip-compressed tar archive

```bash
tar -xzvf files.tar.gz
```

### List archive contents without extracting

```bash
tar -tvf files.tar
tar -tzvf files.tar.gz
```

## 14.4 Understand the tar options

| Option | Meaning |
|---|---|
| `c` | Create an archive |
| `x` | Extract an archive |
| `t` | List archive contents |
| `z` | Use gzip compression/decompression |
| `v` | Verbose output |
| `f` | The next argument is the archive filename |

The `f` option is followed by the archive name.

### What happens with `.tar.gz`?

Conceptually:

```text
files and directories
        |
        v
tar combines them into .tar
        |
        v
gzip compresses the .tar
        |
        v
.tar.gz
```

When you run:

```bash
tar -xzvf apache-tomcat-10.1.61.tar.gz
```

tar handles gzip decompression and archive extraction as part of one command. You do not normally need to run `gunzip` separately.

**Important correction:** `tar -cvf` creates an archive but does not compress it. Use `-czvf` for gzip compression.
