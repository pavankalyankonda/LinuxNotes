# 18. Finding Files and Inspecting File Types

## 18.1 `find`

Searches for files and directories based on conditions.

```bash
find / -name file1 2>/dev/null
find /etc -name "*.conf"
find /var/log -type f
find /home/konda -type d
```

Common options:

| Option | Meaning |
|---|---|
| `-name` | Match filename (case-sensitive) |
| `-iname` | Match filename (case-insensitive) |
| `-type f` | Regular files |
| `-type d` | Directories |
| `-mtime -1` | Modified within the last 24 hours (day-based rounding applies) |
| `-size +100M` | Larger than 100 MB |

Example:

```bash
find /var/log -type f -size +100M
```

`2>/dev/null` redirects error output (file descriptor 2) to `/dev/null`, hiding permission-denied messages. It does not fix permissions; it only suppresses those messages.

## 18.2 `file`

Identifies the type of a file by examining its contents.

```bash
file filename
file archive.tar.gz
file /bin/ls
```

A filename extension is not a guarantee of the actual file format.

## 18.3 `diff`

Compares text files line by line.

```bash
diff file1 file2
diff -u file1 file2
```

`-u` produces unified output, which is commonly used in code reviews and patches.
