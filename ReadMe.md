# Linux Administration – Learning Notes

This repository contains my Linux learning notes, commands, and practical examples covering Linux administration and troubleshooting.

The goal is to build strong Linux fundamentals and practical skills.

## Learning Approach

- Simple explanations of Linux concepts.
- Frequently used commands with examples.
- Practical exercises and troubleshooting scenarios.
- Notes focused on real-world Linux administration and DevOps tasks.

## Environment

- OS: Ubuntu 22.04 LTS
- Shell: Bash
- Practice: Linux Virtual Machine
