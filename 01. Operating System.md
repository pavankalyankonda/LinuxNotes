# Operating System (OS) and Kernel

## 1. What is an Operating System (OS)?

An Operating System (OS) is system software that acts as an interface between the user, applications, and computer hardware.

It manages the computer's hardware resources and provides an environment in which applications can run.

Without an operating system, applications would have to communicate directly with hardware, which would make software development and system management extremely complicated.

### Example

You want to:
- Create a file.
- Run an application.
- Connect to another server using SSH.
- Check memory utilization.
- Install software.
- Create and manage users.

The operating system provides the necessary services and manages the underlying hardware to perform these operations.

### Main responsibilities of an OS

| Responsibility | What it does | example |
|---|---|---|
| Process management | Creates, schedules and terminates processes | `ps`, `top` |
| Memory management | Allocates and manages RAM | `free -h` |
| File management | Manages files and directories | `ls`, `mkdir`, `cp` |
| Device management | Manages hardware devices | Disk, network card |
| Security | Controls access and permissions | `chmod`, `chown` |
| User management | Manages system users and groups | `useradd`, `groupadd` |
| Networking | Provides networking capabilities | `ip`, `ss`, `ping` |

**In simple terms:** The OS manages the complete system and makes it possible for users and applications to use hardware resources efficiently.

## 2. What is a Kernel?

The kernel is the core component of an operating system.

It directly interacts with the hardware and manages the resources required by applications and other system components.

The kernel acts as a bridge between software and hardware.

For example, when an application wants to read a file from a disk, it cannot directly control the physical disk hardware. It requests the kernel to perform the operation.

The kernel handles that request through the appropriate device driver and hardware interface.

### Main responsibilities of a Kernel

| Responsibility | Explanation |
|---|---|
| Process management | Creates processes, schedules CPU time and manages their execution |
| Memory management | Allocates RAM and manages virtual memory |
| Device management | Communicates with hardware through device drivers |
| File system management | Provides file system operations |
| Networking | Implements core networking functionality |
| System calls | Provides an interface for applications to request kernel services |

### Example: Reading a file

Suppose you execute:

`cat /etc/hostname`

What happens?

1. The `cat` command runs as a user-space process.
2. It requests the operating system to read the specified file.
3. The request reaches the kernel through a system call.
4. The kernel accesses the file system and retrieves the required data.
5. The data is returned to the `cat` process.
6. The contents are displayed in the terminal.

The application does not directly access the physical disk. The kernel manages that interaction.

## 3. Difference Between OS and Kernel

The OS and kernel are related, but they are not the same thing.

| Operating System | Kernel |
|---|---|
| Complete system software environment | Core component of the OS |
| Provides services to users and applications | Provides core services to the OS and applications |
| Includes kernel and supporting system software | Manages hardware and system resources |
| Includes utilities, libraries, services and applications | Handles CPU, memory, devices and system calls |
| Example: Ubuntu | Example: Linux kernel |

**Remember:**

An operating system is the complete package, whereas the kernel is its core.

## 4. Understanding Ubuntu Linux

Ubuntu is a Linux distribution based on Debian.

It combines the Linux kernel with system utilities, libraries, package management tools, applications and other components to provide a complete operating system.

Ubuntu is not the kernel itself.

It uses the Linux kernel.

### Important Ubuntu components

| Component | Purpose |
|---|---|
| Linux Kernel | Manages hardware and system resources |
| GNU Utilities | Provides commands and system tools |
| Bash | Command-line shell |
| systemd | Manages system services and system state |
| APT | Installs and manages software packages |
| Libraries | Provide reusable functionality to applications |
| Device Drivers | Enable communication with hardware |
| Applications | Software used to perform specific tasks |

### How these components fit together

Think of an Ubuntu server as the following layers:

1. **Hardware:** CPU, RAM, disks and network cards.
2. **Kernel:** Linux kernel manages hardware and system resources.
3. **System libraries and utilities:** Provide functionality to applications and users.
4. **System services:** Services such as SSH, cron and networking.
5. **Shell and applications:** Bash, commands and other applications.
6. **User:** Interacts with the system through commands or applications.

### Check the running kernel version

Execute:

`uname -r`

Example output:

`6.8.0-1051-azure` if using an Azure Ubuntu VM

Explanation:

- `6.8.0` – Kernel version.
- `1051` – Ubuntu kernel build/revision information.
- `azure` – Indicates an Azure-specific kernel flavour.

Your Ubuntu Azure VM can use an Azure-optimized kernel.

### Get complete kernel information

`uname -a`

This displays:
- Kernel name.
- Hostname.
- Kernel release.
- Kernel version/build information.
- Machine architecture.

### Check kernel details

`cat /proc/version`

This displays kernel version information, compiler information and build details.

## 6. User Space vs Kernel Space

Linux separates execution into two important areas:

### Kernel Space

Kernel space is where the Linux kernel executes with privileged access to system resources.

It can:
- Manage CPU scheduling.
- Manage memory.
- Communicate with hardware.
- Execute device drivers.
- Handle system calls.

### User Space

User space is where regular applications and user processes execute with restricted privileges.

Examples:
- Bash
- SSH
- `cat`
- `ls`
- Nginx
- Docker
- Python applications

Applications cannot directly perform privileged hardware operations. They request the kernel to perform those operations.

### Example

When you execute:

`free -h`

The `free` utility runs in user space.

It reads memory information exposed by the kernel through `/proc/meminfo`.

The kernel maintains the underlying memory information.

### Comparison

| Kernel Space | User Space |
|---|---|
| Runs the kernel | Runs applications |
| Privileged execution | Restricted execution |
| Direct access to system resources | Requests resources through kernel interfaces |
| Kernel and kernel modules | Bash, SSH, Nginx, utilities |

## 7. What are System Calls?

A system call is a mechanism through which a user-space application requests a service from the kernel.

Applications cannot directly access all kernel functionality, so they use system calls.

### Common system calls

| System Call | Purpose |
|---|---|
| `open()` | Opens a file |
| `read()` | Reads data |
| `write()` | Writes data |
| `close()` | Closes a file descriptor |
| `fork()` | Creates a new process |
| `execve()` | Executes a program |
| `wait()` | Waits for a child process |
| `socket()` | Creates a network socket |
