# 9. CPU Architecture and Binary Compatibility

A Linux executable must be built for a compatible CPU architecture and operating-system environment.

## 9.1 Common 64-bit architectures

| `uname -m` output | Common download label | Meaning |
|---|---|---|
| `x86_64` | `amd64` or `x86_64` | 64-bit x86, used by most Intel and AMD PCs/servers |
| `aarch64` | `arm64` | 64-bit ARM |
| `i386`, `i686` | `386` or `i386` | 32-bit x86 |
| `armv7l` | Often `armv7` or `armhf` | 32-bit ARM variant |

`x86_64` and `amd64` refer to the same 64-bit x86 architecture. `aarch64` and `arm64` refer to the same 64-bit ARM architecture.

## 9.2 Check before downloading a tool

```bash
uname -m
dpkg --print-architecture
lscpu
```

Example:

```text
uname -m
x86_64
```

Choose a compatible download such as:

```text
terraform_linux_amd64.zip
kubectl-linux-amd64
```

If the machine reports `aarch64`, choose the corresponding ARM64 build.
