# 17. Viewing and Editing Files

## 17.1 `cat`

Displays file contents. It can also write content using shell redirection.

```bash
cat file.txt
cat file1.txt file2.txt
cat > newfile.txt
```

After `cat > newfile.txt`, type content and press `Ctrl+D` to finish. This overwrites the target file.

Append instead of overwrite:

```bash
cat >> newfile.txt
```

Again, press `Ctrl+D` when finished.

For large files, use `less` rather than printing everything to the terminal.

## 17.2 `head`

Displays the beginning of a file. By default, it shows 10 lines.

```bash
head /var/log/syslog
head -n 20 /var/log/syslog
```

## 17.3 `tail`

Displays the end of a file. By default, it shows 10 lines.

```bash
tail /var/log/syslog
tail -n 20 /var/log/syslog
```

Follow a log as new lines are written:

```bash
tail -f /var/log/syslog
```

`-f` means follow. The command waits and prints new lines as they are appended. Press `Ctrl+C` to stop.

For logs that may be rotated, `tail -F` can be more useful because it follows the filename and retries if the file is recreated:

```bash
tail -F /var/log/myapp/application.log
```

## 17.4 `less`

`less` opens an interactive viewer instead of printing the entire file at once.

```bash
less /var/log/syslog
```

Useful keys inside `less`:

| Key | Action |
|---|---|
| `↑` / `↓` | Move up/down |
| `Space` | Next page |
| `b` | Previous page |
| `g` | Beginning of file |
| `G` | End of file |
| `/error` | Search for `error` |
| `n` | Next search result |
| `N` | Previous search result |
| `q` | Quit |

## 17.5 `more`

```bash
more /var/log/syslog
```

`more` is a basic page-by-page viewer. `less` offers more navigation and search features.

Memory aid:

```text
head = beginning
tail = end
less = interactive browsing
more = basic page-by-page browsing
```

## 17.6 Text editors

```bash
nano notes.txt
vim notes.txt
```

- `nano` is beginner-friendly and shows common shortcuts.
- `vim` is a powerful modal editor.
- `cat` is mainly for displaying or streaming text, not interactive editing.

## 17.7 Create an empty file or update timestamps

```bash
touch newfile.txt
```

`touch` creates an empty file if it does not exist. If it exists, it updates its access/modification timestamps (subject to options and filesystem behaviour).
