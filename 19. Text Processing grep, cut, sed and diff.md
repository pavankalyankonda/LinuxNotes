# 19. Text Processing: grep, cut, sed and diff

These tools are especially useful when inspecting logs, configuration files and command output.

## 19.1 grep

`grep` searches input for lines matching a pattern (commonly a regular expression).

```bash
grep "hello" file1
grep "error" application.log
grep -i "permit" /etc/ssh/sshd_config
grep -n "error" application.log
grep -v "debug" application.log
```

Useful options:

| Option | Meaning |
|---|---|
| `-i` | Ignore case |
| `-n` | Show line numbers |
| `-v` | Show lines that do not match |
| `-r` | Search recursively |
| `-E` | Use extended regular expressions |
| `-w` | Match whole words |

### Anchors

```bash
grep '^t' file1       # Lines beginning with t
grep 't$' file1       # Lines ending with t
```

- `^` = beginning of line
- `$` = end of line

### Search command output

```bash
ls -l | grep "file1"
ls -l | grep '^d'
```

The second example selects long-listing lines beginning with `d`, which indicates directories.

### Search SSH configuration

```bash
grep -i "permit" /etc/ssh/sshd_config
```

You usually do not need `cat` before `grep`; use:

```bash
grep -i "permit" /etc/ssh/sshd_config
```

rather than:

```bash
cat /etc/ssh/sshd_config | grep -i "permit"
```

The shorter form avoids an unnecessary process.

## 19.2 cut

`cut` extracts selected fields or character positions from each line.

Example: `/etc/passwd` uses colon-separated fields. Print the first field (username):

```bash
cut -d: -f1 /etc/passwd
```

- `-d:` = use colon as the delimiter
- `-f1` = print field 1

Other examples:

```bash
cut -d: -f1,3 /etc/passwd   # Username and UID
cut -c1-10 file.txt         # Characters 1 through 10
```

## 19.3 sed

`sed` is a stream editor used to transform text.

Basic substitution syntax:

```bash
sed 's/old_text/new_text/' file_name
```

By default, this replaces the first matching occurrence on each line in the output.

Examples:

```bash
sed 's/linux/ansible/' test_file
sed 's/linux/ansible/i' test_file
sed 's/Linux/ansible/g' test_file
sed 's/linux/ansible/ig' test_file
```

- `s` = substitute
- `i` = case-insensitive matching (GNU sed)
- `g` = replace all matches on each line rather than only the first

### Modify the original file

```bash
sed -i 's/Linux/ansible/g' testfile
```

`-i` edits the file in place. On GNU sed (as on Ubuntu), `-i.bak` creates a backup:

```bash
sed -i.bak 's/Linux/ansible/g' testfile
```

**Caution:** Check the output without `-i` first, especially when changing configuration files.
