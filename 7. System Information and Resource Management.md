# 7. System Information and Resource Management

## 7.1 Identify the OS and kernel

```bash
uname -a                  # Kernel and machine information
uname -r                  # Kernel release
uname -m                  # Machine architecture
cat /etc/os-release       # Distribution name and version
hostname                  # System hostname
hostnamectl               # Hostname and OS information
```

## 7.2 CPU information

```bash
lscpu                     # Human-readable CPU details
cat /proc/cpuinfo         # Detailed per-CPU information
nproc                     # Number of available processing units
```

## 7.3 Memory information

```bash
free -h                   # Memory and swap in human-readable units
free -m                   # Memory and swap in MiB
cat /proc/meminfo         # Detailed kernel memory information
```

`free -h` is a useful first command when investigating memory pressure. Pay attention to `available`, not just `free`: Linux uses otherwise-unused RAM for caches and can reclaim much of it when applications need memory.

## 7.4 Filesystem capacity: `df`

`df` reports filesystem-level disk space.

```bash
df -h                     # Mounted filesystem capacity in readable units
df -hT                    # Also show filesystem type
df -i                     # Show inode usage
```

Think: **Which filesystem is full?**

## 7.5 Directory usage: `du`

`du` reports disk usage of files and directories.

```bash
du -sh /var               # Total size of /var
du -sh /var/log           # Total size of /var/log
du -h /var                # Usage for directories/files under /var
du -h /var | sort -hr | head
```

Useful options:

- `-s` = summary, one total per specified path
- `-h` = human-readable units
- `-x` = stay on the same filesystem
- `-d 1` = limit directory traversal to one level of depth

### Find the largest top-level directories under `/`

```bash
sudo du -xhd1 / | sort -hr | head -n 10
```

Breakdown:

- `sudo` = read directories that require elevated permissions
- `du` = calculate disk usage
- `-x` = do not cross filesystem boundaries
- `-h` = human-readable sizes
- `-d1` = show only the first directory level
- `sort -hr` = sort human-readable sizes in reverse order (largest first)
- `head -n 10` = show the first 10 results

**Do not confuse `df` and `du`:**

| Command | Question answered |
|---|---|
| `df -h` | How full is each mounted filesystem? |
| `du -sh /path` | How much space does this directory consume? |
| `du -xhd1 /` | Which top-level directories consume space on this filesystem? |

If `df` reports a full filesystem but `du` cannot account for the space, investigate deleted-but-open files, reserved blocks, snapshots and filesystem metadata.

## 7.6 Locate commands

```bash
which ls                   # Locate a command using PATH
whereis ls                 # Locate binary, source and manual-page files
type ls                    # Show how the shell resolves the command
command -v ls              # Portable command lookup
```

`which` and `whereis` are not identical. `which` searches the command path; `whereis` can locate related binary and manual files in known locations. `type` is especially useful because a command name may resolve to an alias, function or shell builtin.
