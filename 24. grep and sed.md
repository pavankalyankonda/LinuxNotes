# **grep and sed**

## **1. grep (Global Regular Expression Print)**

`grep` is used to search for specific words, characters, or patterns in files and command output.

**Examples:**

```
# Search for the word hello in file1
grep hello file1

# Search for the character t
grep t file1

# Search for lines starting with t (^ represents beginning of line)
grep ^t file1

# Search for Permit in SSH configuration
cat /etc/ssh/sshd_config | grep Permit

# Case-insensitive search (Permit, PERMIT, permit)
cat /etc/ssh/sshd_config | grep -i permit

# Search for file1 in ls output
ls -l | grep file1

# Display only directories (d represents directory)
ls -l | grep ^d
```

**Useful options:**

| Option | Description            |
| ------ | ---------------------- |
| `-i`   | Ignore case            |
| `-v`   | Exclude matching lines |
| `-n`   | Display line numbers   |
| `-r`   | Search recursively     |
| `-c`   | Count matching lines   |

**Note:**

- `^` represents the beginning of a line.
- `$` represents the end of a line.
- `|` (pipe) passes the output of one command as input to another command.

## **2. sed (Stream Editor)**

`sed` is used to search, replace, and modify text in files or command output. It is commonly used for text replacement and configuration management.

**Syntax:**

```
sed 's/old_text/new_text/' filename
```

Here:

- `s` → Substitute (replace).
- `old_text` → Text to search for.
- `new_text` → Replacement text.

**Examples:**

```
# Replace the first occurrence of linux on each line
sed 's/linux/ansible/' testfile

# Replace ignoring case
sed 's/linux/ansible/i' testfile

# Replace all occurrences on each line
sed 's/linux/ansible/g' testfile

# Replace all occurrences, ignoring case
sed 's/linux/ansible/ig' testfile

# Modify the original file directly
sed -i 's/linux/ansible/ig' testfile
```

**Additional examples:**

```
# Delete line 3
sed '3d' testfile

# Delete lines containing linux
sed '/linux/d' testfile

# Display only lines 1 to 5
sed -n '1,5p' testfile
```

**Important options and expressions:**

| Expression | Description                          |
| ---------- | ------------------------------------ |
| `s`        | Substitute text                      |
| `i`        | Ignore case                          |
| `g`        | Replace all occurrences on each line |
| `d`        | Delete matching lines                |
| `p`        | Print matching lines                 |
| `-i`       | Modify the original file directly    |
| `-n`       | Disable automatic printing           |

**Note:** Without `-i`, `sed` displays modified output but does not change the original file. Use `-i` carefully, especially when modifying system configuration files.

**Quick difference:**

- `grep` → Search for text.
- `sed` → Search and modify text.
